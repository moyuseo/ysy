## 第一部分：产品定义

### 1.1 产品名称
药行情（YaoHangQing）— 中药材行情信息平台

### 1.2 产品定位
面向中药材行业的专业行情信息平台，提供实时价格、供求信息、行业资讯、品种百科等一站式服务。融合中药材传统文化底蕴与现代数据驱动设计，以深绿主色调体现中药古典韵味，以红涨绿跌的行情视觉呈现数据动态。

### 1.3 目标用户
| 用户类型 | 核心需求 | 使用场景 |
|---------|---------|---------|
| 中药材经销商/批发商 | 掌握实时行情、寻找货源/客户 | 每日查看价格涨跌、发布供应信息 |
| 中药材种植户/产地供应商 | 了解产地价格、发布供应 | 采收季查看产地价、发布货源 |
| 中药饮片厂/制药企业采购 | 批量采购、价格对比 | 查看多市场报价、发布求购/招标 |
| 中药材行业研究者/分析师 | 历史数据分析、趋势研判 | 查看走势图、阅读品种分析 |

## 第二部分：功能模块详细设计

### 2.1 行情价格系统（P0 核心）

#### 2.1.1 市场价格
- **功能描述**：按市场展示各品种今日价格
- **数据字段**：品种名、规格、产地、市场名、今日价、昨日价、日涨跌、月涨跌、走势标记
- **支持市场**：亳州、安国、玉林、成都、廉桥、禹州、陇西
- **交互行为**：
  - 点击品种名跳转品种详情页
  - 点击表头排序（价格/涨跌幅/品种名）
  - 支持分页，每页20条
- **筛选条件**：品种分类、市场、涨跌方向（全部/上涨/下跌/持平）、关键词搜索

#### 2.1.2 产地价格
- **功能描述**：按产地区县展示各品种价格
- **数据字段**：品种名、规格、产地（省-市-县）、今日价、月涨跌、走势标记
- **交互行为**：同市场价格
- **筛选条件**：品种分类、产地区域、涨跌方向、关键词搜索

#### 2.1.3 价格涨跌
- **功能描述**：按涨跌幅排序展示品种
- **排序方式**：日涨跌、周涨跌、月涨跌
- **视觉标识**：红涨（↑+百分比）、绿跌（↓-百分比）、灰持平（→）
- **快捷筛选**：一键查看"今日变动"品种

#### 2.1.4 历史走势图
- **功能描述**：品种价格走势折线图
- **时间跨度**：1个月 / 3个月 / 6个月 / 1年 / 3年 / 全部
- **数据展示**：X轴日期、Y轴价格、鼠标悬停显示具体数据点
- **交互**：支持多规格叠加对比（如三七120头 vs 60头）

#### 2.1.5 品种搜索
- **功能描述**：全局品种搜索
- **搜索方式**：汉字全称、拼音全拼、拼音首字母
- **交互**：输入即联想下拉，显示品种名+分类+当前价
- **示例**：输入"sq" → 联想"三七"、"蛇床子"

### 2.2 供求信息平台（P0 核心）

#### 2.2.1 供应信息
- **数据字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| 品名 | string | 药材名称 |
| 规格 | string | 如"统货"、"120头"、"选货" |
| 产地 | string | 省-市-县 |
| 数量 | string | 如"20吨"、"500公斤" |
| 价格 | string | 如"电议"、"¥35/公斤" |
| 联系电话 | string | 手机号 |
| 图片 | string[] | 药材实拍图（0-3张） |
| 是否推广 | boolean | 推广标识 |
| 发布时间 | string | 日期 |

- **展示方式**：卡片式，左图右文
- **筛选条件**：品种分类、产地区域、发布时间

#### 2.2.2 求购信息
- **数据字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| 品名 | string | 药材名称 |
| 规格 | string | 要求规格 |
| 产地要求 | string | 不限/指定产地 |
| 交货地址 | string | 省-市 |
| 需求数量 | string | 如"30吨" |
| 已报价人数 | number | 已报价供应商数 |
| 剩余天数 | number | 采购截止倒计时 |
| 发布时间 | string | 日期 |

- **交互**：点击"抢先报价"进入报价流程

#### 2.2.3 采购招标
- **数据字段**：公司名称、采购品种列表、截止日期、联系方式
- **展示方式**：列表式，显示公司名+采购品种摘要+日期

#### 2.2.4 产地直供
- **功能描述**：产地一手货源专区，与供应信息类似但强调"产地直发"
- **额外标识**：产地认证标识、GAP基地标识

### 2.3 资讯信息中心（P1）

#### 2.3.1 品种分析
- **内容**：单品深度行情分析文章，含走势预测、供需分析
- **字段**：标题、摘要、正文（富文本）、关联品种、发布时间、阅读量
- **置顶规则**：重要分析文章置顶显示

#### 2.3.2 药市动态
- **内容**：市场整体走势、多品种综合点评
- **栏目**："中药材今日视点"定期综合播报

#### 2.3.3 产地快报
- **内容**：各产地最新产新、采收动态
- **字段**：标题、产地、关联品种、发布时间

#### 2.3.4 行业新闻
- **内容**：政策法规、行业事件
- **分类标签**：政策法规、行业标准、企业动态

#### 2.3.5 涨跌盘点
- **内容**："六大牛气品种"、"九大跌价品种"等定期盘点文章
- **特色**：图文并茂，含品种价格走势缩略图

### 2.4 品种详情页（P0）

品种详情页是全站信息密度最高的页面，整合了该品种的所有关联数据。

#### 2.4.1 品种头部
- 品名 + 别名（括号内）
- 分类标签（如"根及根茎类"）
- 科属标签（如"五加科"）

#### 2.4.2 价格概览面板
- 各市场最新报价（市场名 + 规格 + 价格 + 涨跌）
- 各产地最新报价（产地 + 规格 + 价格 + 涨跌）
- 红涨绿跌视觉标识

#### 2.4.3 价格走势图
- 折线图，支持1月/3月/6月/1年/全部切换
- 鼠标悬停显示数据点详情
- 可选多规格叠加对比

#### 2.4.4 Tab内容区
| Tab | 内容 |
|-----|------|
| 供应信息 | 该品种最新供应列表 |
| 求购信息 | 该品种最新求购列表 |
| 相关资讯 | 该品种相关分析文章 |
| 药材知识 | 性味归经、功效主治、用法用量、食用禁忌 |
| 种植技术 | 种植方法、田间管理、采收加工 |

#### 2.4.5 品种基本信息表
| 字段 | 示例 |
|------|------|
| 品名 | 三七 |
| 别名 | 田七、金不换、参三七 |
| 科属 | 五加科人参属 |
| 性味 | 甘、微苦，温 |
| 归经 | 肝、胃 |
| 功效 | 散瘀止血，消肿定痛 |
| 主产地 | 云南文山、广西田阳 |
| 常见规格 | 20头、40头、60头、80头、120头、无数头、剪口、筋条、花、叶 |
| 采收时间 | 7-8月（春七）、12-1月（冬七） |

### 2.5 涨跌排行（P0）

#### 2.5.1 涨幅排行

#### 2.5.2 跌幅排行
- 按跌幅降序排列

- 显示字段：排名、品种名、搜索热度指数、当前价、今日涨跌

#### 2.5.4 牛气品种
- 长期强势品种盘点
- 展示近3个月持续上涨的品种

### 5.5 组件样式规范

**涨跌标识**：
- 上涨：红色文字 + ↑箭头 + 红色浅背景标签
- 下跌：绿色文字 + ↓箭头 + 绿色浅背景标签
- 持平：灰色文字 + →箭头

**价格表格**：
- 表头：深绿背景 + 白色文字
- 偶数行：白色背景
- 奇数行：#FAFAF5 背景
- 悬停行：#E8F5E9 浅绿背景

**卡片**：
- 白色背景 + 1px #E0E0E0 边框
- 圆角 8px
- 悬停：轻微阴影 + 上移2px

**按钮**：
- 主按钮：深绿背景 + 白色文字
- 次按钮：白色背景 + 深绿边框 + 深绿文字
- 悬停：加深10%色值
