# 中药材行情信息网站 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
药行情 - 中药材行情信息平台

### 1.2 产品定位
面向中药材行业的专业行情信息平台，提供实时价格、供求信息、行业资讯、品种百科等一站式服务。融合中药材传统文化底蕴与现代数据驱动设计，以深绿主色调体现中药古典韵味，以红涨绿跌的行情视觉呈现数据动态。

### 1.3 目标用户
- 中药材经销商/批发商
- 中药材种植户/产地供应商
- 中药饮片厂/制药企业采购人员
- 中药材行业研究者/分析师

## 2. 功能模块

### 2.1 行情价格系统（核心）
- **市场价格**：按市场（亳州、安国、玉林、成都等）展示各品种今日价格
- **产地价格**：按产地展示各品种价格
- **价格涨跌**：日/周/月涨跌排行，红涨绿跌
- **历史走势**：价格走势折线图，支持1月/3月/6月/1年/全部
- **品种搜索**：支持拼音首字母、汉字搜索

### 2.2 供求信息平台
- **供应信息**：品种/规格/产地/数量/价格/联系方式
- **求购信息**：品种/规格/交货地址/需求数量/报价人数
- **采购招标**：企业采购计划发布
- **产地直供**：产地一手货源展示

### 2.3 资讯信息中心
- **品种分析**：单品深度行情分析文章
- **药市动态**：市场整体走势分析
- **产地快报**：各产地最新动态
- **行业新闻**：政策法规、行业事件

### 2.4 品种详情页
- 基本信息表：品名、别名、科属、产地、规格
- 实时价格：各市场/产地最新报价
- 价格走势图：历史价格折线图
- 供求信息：该品种的供应/求购列表
- 相关资讯：该品种的分析文章
- 药材知识：性味归经、功效主治

### 2.5 数据工具
- **涨跌排行榜**：今日/本周/本月涨跌幅排行
- **查询排行榜**：热门搜索品种排行
- **品种分类浏览**：按根茎类、果实类、全草类等分类

### 2.6 知识百科
- **药材知识**：性味归经、功效主治、用法用量
- **种植技术**：种植方法、田间管理、采收加工
- **新闻法规**：政策法规、行业标准

### 2.7 实用小工具
- 品种搜索（支持拼音/首字母）
- 行情日历（产新时间表）
- 药典标准查询

## 4. 视觉设计要求

### 4.1 色彩体系
- **主色**：深绿 #1B5E20（中药古典底蕴）
- **辅助绿**：#2E7D32, #4CAF50, #81C784
- **涨色**：#D32F2F（红色，价格上涨）
- **跌色**：#2E7D32（绿色，价格下跌）
- **背景**：#FAFAF5（微黄暖白，宣纸质感）
- **文字**：#1A1A1A（主文字），#666666（辅助文字）
- **金色点缀**：#C9A96E（传统中药金）

### 4.2 字体
- 标题：思源宋体 / Noto Serif SC
- 正文：思源黑体 / Noto Sans SC
- 数据：DIN / JetBrains Mono

### 4.3 设计风格
- 传统中药文化底蕴 + 现代数据驱动
- 信息密度高，类似金融行情网站
- 红涨绿跌的行情视觉
- 适当使用传统纹样装饰（如云纹、回纹边框）
